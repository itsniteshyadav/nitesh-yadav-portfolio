# Nitesh Yadav Portfolio

A responsive portfolio website built from the structure/navigation of the reference portfolio, with a new editorial dark/lime/violet visual theme and Nitesh Yadav's CV, projects, training and certificates.

## Run locally
Open `index.html` in a browser.

## Deploy to Vercel
Upload this folder/repository to Vercel. No build step is required.

## Included
- Nitesh Yadav CV PDF
- Oracle Cloud Infrastructure Certified AI Foundations Associate certificate
- Oracle AI Database Certified Foundations Associate certificate
- LPU Basics of DSA training certificate
- Responsive navigation and sections for Skills, Projects, Certifications, Training, Education and Contact
